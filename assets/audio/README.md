# Heavens call audio

Drop `.ogg` files here with exactly these names. Any file that is missing is simply silent.
Credits go in `CREDITS.md`. No music, dialogue or jump scares.

| File | Purpose | Kind | Rough length |
|------|---------|------|--------------|
| `wind_loop` | steady mountain wind bed | loop | 30-60 s |
| `wind_strong_loop` | stronger gusting wind, builds toward the summit | loop | 30-60 s |
| `ambience_eerie_loop` | low unsettling air, from the eerie stretch on | loop | 30-60 s |
| `footstep_gravel_1..4` | steps on the trail | one-shot | 0.3-0.5 s |
| `footstep_rock_1..4` | steps off the trail | one-shot | 0.3-0.5 s |
| `thunder_distant_1..3` | far thunder after a flash | one-shot | 4-8 s |
| `thunder_clap` | the summit sequence's clap | one-shot | 3-6 s |
