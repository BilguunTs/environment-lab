# Heavens call audio credits

All sources are CC0 1.0 (public domain dedication), checked on each entry's own OpenGameArt page.
No credit is required; it is given anyway. Edits were made with ffmpeg 9.0.1 (libvorbis, quality 4).
Every shipped file is mono, 44.1 kHz, Ogg Vorbis.
