# Stage 8 Implementation Plan: comparison, preset saving, visual debugging

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shorten the experiment loop inside the running scene:
- live A/B comparison and saved side-by-side pairs
- presets saved to disk
- four visual-debugging tools: render modes, value probe, perf readout, light gizmos

**Architecture:**
- **Compare.** A `Compare` node owns A/B. It talks to the scene only through the playground's existing `get_state()` / `apply_state()` / `get_param()` interface, and draws its split view through a `CompareView` overlay.
- **Presets.** Saving extends `presets.gd` with static helpers and a `ConfigFile`.
- **Debug tools.** Each is a small self-contained node (`ValueProbe`, `PerfHud`, `LightGizmos`) that the playground creates in `_ready()` and exposes as non-state parameters.
- **Tests.** A tiny GDScript test runner drives the real scene.

**Tech Stack:** Godot 4.6 (mono build, pure GDScript), Forward+ renderer. No plugins.

**Spec:** `docs/superpowers/specs/2026-10-12-stage-8-design.md`. Read it before starting. This plan refines it in three places, noted in the tasks:
- A is captured on entering split view, not on every pin.
- A permanent test suite replaces the temporary `--selftest-compare` flag.
- The probe's hole check uses a threshold, because the hole breathes.

## Global Constraints

- **Engine:** Godot **4.6**, pure GDScript, no addons, no paid or cloud services.
- **Style:** tabs for indentation, `##` doc comments, typed variables, the existing naming style. Read neighbouring code before writing.
- **No git:** the project is **not** a git repo. There are no commit steps; every task ends with a full-suite checkpoint.
- **Compare keys:** **P** pins A, **X** (hold) shows A, **Z** toggles split view, **F2** cycles the render mode.
- **Not compared:** `EXCLUDE = ["view", "guides_grid", "guides_center", "guides_aspect", "value_mode", "value_squint", "value_split"]`.
- **Compare timings:** `SETTLE_FRAMES = 10`; `RECAPTURE_DELAY = 0.5` s.
- **Debug parameters:** `debug_draw`, `probe`, `perf_hud` and `light_gizmos` go through `get_param`/`set_param` and are **never** added to `PARAM_ORDER`.
- **User presets:** stored in `res://presets/user_presets.cfg`, as overrides on top of the default state, with `view` always stored. Names must match `^[A-Za-z0-9 _\-]+$`, and may not be a built-in preset name or `Reset`.
- **Luminance:** Rec.709 (`0.2126 R + 0.7152 G + 0.0722 B`) of the final, tonemapped frame.
- **Probe and panel:** probe `SAMPLE_INTERVAL = 0.25` s, `BINS = 32`, `DOWNSAMPLE = 8`; panel diff shows at most `DIFF_LINES = 8` lines; split handle `HANDLE = 12` px.
- **Overlays:** anything drawn over the 3D view (panel, HUD, compare view, probe, perf HUD) joins the group `"overlay"`, so captures can hide it.

**Test command.** Run it from the project root in Bash. The `--import` step registers new `class_name`s and must run whenever a task adds one.

```bash
GODOT=/d/softwares/Godot_v4.6-stable_mono_win64/Godot_v4.6-stable_mono_win64_console.exe
"$GODOT" --headless --path . --import >/dev/null 2>&1
"$GODOT" --path . -s res://tests/run.gd                    # full suite, opens a window (image tests run)
"$GODOT" --path . -s res://tests/run.gd -- --only=compare  # only files whose name contains "compare"
"$GODOT" --headless --path . -s res://tests/run.gd         # logic only, image tests SKIP
```

Exit code 0 means everything passed. The output lists `PASS` / `FAIL` / `SKIP` per test, then a summary line.

## Review Focus

1. **Window loses focus while X is held.** The key release never arrives. A must not stay stuck on screen; the scene returns to B (the test is in Task 4).
2. **Hand-edited `user_presets.cfg` with a syntax error.** Saving must refuse and leave the file untouched, not silently wipe your presets (Task 2).
3. **Clicking into the 3D view while the preset name field has focus.** Typing mode must end so WASD and the hotkeys work again (Task 3).
4. **X, Z or Save pair pressed while a capture is running.** They're ignored, and the scene ends on B (Task 5).
5. **Entering Scout (F) while showing A or in split view.** Both are left cleanly, because A/B needs one fixed camera (Tasks 4 and 5).

`tests/case.gd`:

```gdscript
extends RefCounted
## Base for test files. tests/test_*.gd extend this and define `test_*` methods taking the
## playground; methods may await. A failed check records a message and the test carries on.

var tree: SceneTree
var failures: Array[String] = []
var skipped := ""


func check(condition: bool, message: String) -> void:
	if not condition:
		failures.append(message)


func check_eq(actual: Variant, expected: Variant, message: String) -> void:
	var numeric := typeof(actual) in [TYPE_INT, TYPE_FLOAT] and typeof(expected) in [TYPE_INT, TYPE_FLOAT]
	var same := float(actual) == float(expected) if numeric else (typeof(actual) == typeof(expected) and actual == expected)
	if not same:
		failures.append("%s: expected %s, got %s" % [message, var_to_str(expected), var_to_str(actual)])


func check_near(actual: float, expected: float, tolerance: float, message: String) -> void:
	if absf(actual - expected) > tolerance:
		failures.append("%s: expected %.3f ± %.3f, got %.3f" % [message, expected, tolerance, actual])


func frames(count: int) -> void:
	for i in count:
		await tree.process_frame


func seconds(duration: float) -> void:
	await tree.create_timer(duration).timeout


## Image tests need a real renderer: the headless display server draws nothing.
## Usage: `if not needs_window(): return`
func needs_window() -> bool:
	if DisplayServer.get_name() == "headless":
		skipped = "needs a window (run without --headless)"
		return false
	return true
```

- [ ] **Step 2: Write the runner**

`tests/run.gd`:

```gdscript
extends SceneTree
## Runs every tests/test_*.gd against a live playground scene.
##   Godot --path . -s res://tests/run.gd                  all tests (opens a window)
##   Godot --headless --path . -s res://tests/run.gd       logic only; image tests are skipped
##   Godot --path . -s res://tests/run.gd -- --only=name   files whose name contains "name"
## Exit code 0 = everything passed.

const TEST_DIR := "res://tests"


func _initialize() -> void:
	_run.call_deferred()


func _run() -> void:
	var only := ""
	for arg in OS.get_cmdline_user_args():
		if arg.begins_with("--only="):
			only = arg.trim_prefix("--only=")
	var pg: Node = load("res://scenes/playground.tscn").instantiate()
	root.add_child(pg)
	for i in 30:  # let shadows, SSAO and the forest settle
		await process_frame
	var passed := 0
	var failed := 0
	var skipped := 0
	var files := Array(DirAccess.get_files_at(TEST_DIR))
	files.sort()
	for file: String in files:
		if not (file.begins_with("test_") and file.ends_with(".gd")):
			continue
		if only != "" and not file.contains(only):
			continue
		var script: GDScript = load(TEST_DIR.path_join(file))
		for method in script.get_script_method_list():
			var test_name: String = method["name"]
			if not test_name.begins_with("test_"):
				continue
			var case = script.new()
			case.tree = self
			pg.reset_scene()
			if case.has_method("before_each"):
				await case.before_each(pg)
			await case.call(test_name, pg)
			if case.has_method("after_each"):
				await case.after_each(pg)
			var label := "%s::%s" % [file.get_basename(), test_name]
			if case.skipped != "":
				skipped += 1
				print("SKIP %s (%s)" % [label, case.skipped])
			elif case.failures.is_empty():
				passed += 1
				print("PASS %s" % label)
			else:
				failed += 1
				print("FAIL %s" % label)
				for message in case.failures:
					print("     - %s" % message)
	print("\n%d passed, %d failed, %d skipped" % [passed, failed, skipped])
	quit(1 if failed > 0 else 0)
```

Append to `scripts/presets.gd`, after the closing `}` of `const ALL`:

```gdscript

## Saved presets (plain text: edit by hand, delete a preset by deleting its section).
## res:// is read-only in exported builds; this playground is never exported.
const USER_PATH := "res://presets/user_presets.cfg"
## Names become ConfigFile section headers, so keep them to safe characters.
const NAME_PATTERN := "^[A-Za-z0-9 _\\-]+$"


## Built-in presets followed by the saved ones (built-in names win).
static func all(path := USER_PATH) -> Dictionary:
	var result := ALL.duplicate()
	var cfg := ConfigFile.new()
	if cfg.load(path) != OK:
		return result
	for section in cfg.get_sections():
		if result.has(section):
			continue
		var preset := {}
		for key in cfg.get_section_keys(section):
			preset[key] = cfg.get_value(section, key)
		result[section] = preset
	return result


## The keys of `state` whose values differ from `base`, with the values from `state`.
static func overrides(state: Dictionary, base: Dictionary) -> Dictionary:
	var result := {}
	for key in state:
		if not base.has(key) or not same_value(state[key], base[key]):
			result[key] = state[key]
	return result


static func same_value(a: Variant, b: Variant) -> bool:
	if typeof(a) in [TYPE_FLOAT, TYPE_INT] and typeof(b) in [TYPE_FLOAT, TYPE_INT]:
		return is_equal_approx(float(a), float(b))
	if a is Color and b is Color:
		return a.is_equal_approx(b)
	return typeof(a) == typeof(b) and a == b


## Saves `state` as overrides on top of `default_state` (plus the view, since a preset is also
## a shot). Returns "" on success, otherwise a message for the panel's status line.
static func save_user(preset_name: String, state: Dictionary, default_state: Dictionary, path := USER_PATH) -> String:
	preset_name = preset_name.strip_edges()
	if preset_name.is_empty():
		return "Type a preset name first"
	if RegEx.create_from_string(NAME_PATTERN).search(preset_name) == null:
		return "Use letters, digits, spaces, - or _ in preset names"
	if ALL.has(preset_name) or preset_name == "Reset":
		return "Name taken by a built-in preset"
	var cfg := ConfigFile.new()
	var loaded := cfg.load(path)
	if loaded != OK and loaded != ERR_FILE_NOT_FOUND:
		return "Can't read %s (error %d): fix or delete it first" % [path, loaded]
	if cfg.has_section(preset_name):
		cfg.erase_section(preset_name)
	var values := overrides(state, default_state)
	values["view"] = state.get("view", "Gameplay")
	for key in values:
		cfg.set_value(preset_name, key, values[key])
	DirAccess.make_dir_recursive_absolute(ProjectSettings.globalize_path(path.get_base_dir()))
	var err := cfg.save(path)
	return "" if err == OK else "Could not write %s (error %d)" % [path, err]
```

```gdscript
class_name Compare
extends Node
## A/B comparison from one camera. A is a pinned state; B is always the live scene.
## P pins A, hold X to see A. Talks to the scene only through the playground's
## get_state / apply_state interface, so every parameter is comparable for free.

signal changed  # pinned, flipped, split toggled or A re-captured: HUD and panel refresh

const Presets := preload("res://scripts/presets.gd")
## Not compared: A and B are seen from the same camera, guides and value view.
const EXCLUDE := ["view", "guides_grid", "guides_center", "guides_aspect", "value_mode", "value_squint", "value_split"]

var pg: Node  # the playground
var a_state := {}  # empty = nothing pinned
var showing_a := false
var _b_state := {}  # the live state while A is shown


func has_a() -> bool:
	return not a_state.is_empty()


func compare_state() -> Dictionary:
	var state: Dictionary = pg.get_state()
	for key in EXCLUDE:
		state.erase(key)
	return state


## Why A/B can't run right now, or "" if it can.
func blocked_reason(needs_a := true) -> String:
	if pg.in_scout():
		return "Leave Scout first (F)"
	if needs_a and not has_a():
		return "Pin A first (P)"
	return ""


func pin() -> void:
	var reason := blocked_reason(false)
	if reason != "":
		pg.panel.notify(reason)
		return
	show_a(false)
	a_state = compare_state()
	pg.panel.notify("A pinned: change something, then hold X to compare")
	changed.emit()


func clear() -> void:
	leave()
	a_state = {}
	changed.emit()


## Back to plain B, e.g. before Scout takes over the camera.
func leave() -> void:
	show_a(false)


## Hold-to-flip: true shows A, false returns to the live state B.
func show_a(on: bool) -> void:
	if on == showing_a:
		return
	if on:
		var reason := blocked_reason()
		if reason != "":
			pg.panel.notify(reason)
			return
		_b_state = compare_state()
		pg.apply_state(a_state)
	else:
		pg.apply_state(_b_state)
	showing_a = on
	changed.emit()


## "key: a → b" for every compared parameter that differs between A and B, in panel order.
func diff() -> Array[String]:
	if not has_a():
		return []
	return diff_between(a_state, _b_state if showing_a else compare_state())


static func diff_between(a: Dictionary, b: Dictionary) -> Array[String]:
	var lines: Array[String] = []
	for key in a:
		if b.has(key) and not Presets.same_value(a[key], b[key]):
			lines.append("%s: %s → %s" % [key, fmt(a[key]), fmt(b[key])])
	return lines


## Short, log-friendly value text: 3 significant digits, colours as hex, booleans as on/off.
static func fmt(value: Variant) -> String:
	match typeof(value):
		TYPE_BOOL:
			return "on" if value else "off"
		TYPE_COLOR:
			return "#" + value.to_html(false)
		TYPE_FLOAT, TYPE_INT:
			var v := float(value)
			if is_zero_approx(v):
				return "0"
			var decimals := clampi(2 - floori(log(absf(v)) / log(10.0)), 0, 6)
			return String.num(v, decimals)
	return str(value)


func hud_tag() -> String:
	if not has_a():
		return ""
	return "SHOWING A" if showing_a else "B · A pinned"
```

```gdscript
## the diff underneath, and copies a ready experiment-log row. Returns the PNG path or "".
func save_pair() -> String:
	var reason := blocked_reason()
	if reason != "" or busy:
		pg.panel.notify(reason if reason != "" else "Still capturing, try again")
		return ""
	show_a(false)
	busy = true

	var image_b := await render_state(b)

	var sheet := await compose(image_a, image_b, header, lines)
	var path: String = pg.screenshot_path("compare_" + view_name)
	sheet.save_png(path)
	DisplayServer.clipboard_set(log_row(lines))
	pg.panel.notify("Saved %s (log row copied)" % path.get_file())
	changed.emit()
	return path


## An EXPERIMENT_LOG.md row with Date and Changed filled in; Question, Fixed and Result are yours.
static func log_row(lines: Array[String]) -> String:
	var changed_text := ", ".join(PackedStringArray(lines)) if not lines.is_empty() else "(nothing)"
	return "| %s | | %s | | |" % [Time.get_date_string_from_system(), changed_text]


## Two frames side by side with a text strip below. Godot's Image can't draw text, so this lays
## the pieces out in a temporary 2D SubViewport and grabs its frame.
func compose(left: Image, right: Image, header: String, lines: Array[String]) -> Image:
	var w := left.get_width()
	var h := left.get_height()
	var sub := SubViewport.new()
	sub.size = Vector2i(w * 2, h + STRIP_LINE * (maxi(lines.size(), 1) + 2))
	sub.disable_3d = true
	sub.render_target_update_mode = SubViewport.UPDATE_ONCE
	var background := ColorRect.new()
	background.color = Color(0.05, 0.055, 0.06)
	background.size = Vector2(sub.size)
	sub.add_child(background)
	for i in 2:
		var rect := TextureRect.new()
		rect.texture = ImageTexture.create_from_image(left if i == 0 else right)
		rect.position = Vector2(w * i, 0)
		rect.size = Vector2(w, h)
		sub.add_child(rect)
	var label := Label.new()
	label.position = Vector2(12, h + 6)
	label.add_theme_font_size_override("font_size", 14)
	label.text = header + "\n" + ("\n".join(PackedStringArray(lines)) if not lines.is_empty() else "No differences: A = B")
	sub.add_child(label)
	add_child(sub)
	await RenderingServer.frame_post_draw
	await RenderingServer.frame_post_draw
	var image := sub.get_texture().get_image()
	sub.queue_free()
	return image
```

```gdscript
class_name ValueProbe
extends Control
## Live value readout: luminance under the cursor, frame p5/p50/p95 and a histogram with the
## notan split marked. Measures the final tonemapped frame (what you see, value view included)
## with the same Rec.709 weights as the experiment log. Off by default: every sample reads the
## frame back from the GPU, which costs a few ms.

const SAMPLE_INTERVAL := 0.25
const BINS := 32
const DOWNSAMPLE := 8
const BOX := Vector2(260, 132)
const SPLIT_COLOR := Color(0.95, 0.68, 0.35)

var pg: Node
var cursor_value := -1.0  # -1 = cursor outside the window
var stats := {}
var _timer := 0.0


static func luminance(c: Color) -> float:
	return 0.2126 * c.r + 0.7152 * c.g + 0.0722 * c.b


## Percentiles and histogram of `image`, skipping pixels inside `exclude` (image pixel space).
static func measure(image: Image, exclude: Array[Rect2] = []) -> Dictionary:
	var hist := PackedInt32Array()
	hist.resize(BINS)
	var values := PackedFloat32Array()
	for y in image.get_height():
		for x in image.get_width():
			var p := Vector2(x + 0.5, y + 0.5)
			var skip := false
			for r in exclude:
				if r.has_point(p):
					skip = true
					break
			if skip:
				continue
			var v := clampf(luminance(image.get_pixel(x, y)), 0.0, 1.0)
			values.append(v)
			hist[mini(int(v * BINS), BINS - 1)] += 1
	if values.is_empty():
		return {"p5": 0.0, "p50": 0.0, "p95": 0.0, "hist": hist}
	values.sort()
	var n := values.size()
	return {
		"p5": values[mini(int(0.05 * n), n - 1)],
		"p50": values[mini(int(0.5 * n), n - 1)],
		"p95": values[mini(int(0.95 * n), n - 1)],
		"hist": hist,
	}


func _ready() -> void:
	add_to_group("overlay")
	mouse_filter = MOUSE_FILTER_IGNORE
	set_anchors_and_offsets_preset(PRESET_BOTTOM_RIGHT)
	offset_left = -BOX.x - 16
	offset_top = -BOX.y - 16
	offset_right = -16
	offset_bottom = -16
	visible = false


func _process(delta: float) -> void:
	if not visible:
		return
	_timer += delta
	if _timer < SAMPLE_INTERVAL:
		return
	_timer = 0.0
	sample()
	queue_redraw()


func sample() -> void:
	var frame := get_viewport().get_texture().get_image()
	if frame == null or frame.is_empty():
		return
	var mouse := get_viewport().get_mouse_position()
	var full := Rect2(Vector2.ZERO, Vector2(frame.get_size()))
	cursor_value = luminance(frame.get_pixelv(Vector2i(mouse))) if full.has_point(mouse) else -1.0
	frame.resize(frame.get_width() / DOWNSAMPLE, frame.get_height() / DOWNSAMPLE, Image.INTERPOLATE_BILINEAR)
	# Skip the panel, HUD and this box; full-screen overlays (split view) are part of the picture.
	var exclude: Array[Rect2] = []
	for node in get_tree().get_nodes_in_group("overlay"):
		if node is Control and node.is_visible_in_tree():
			var r: Rect2 = node.get_global_rect()
			if r.get_area() < full.get_area() * 0.5:
				exclude.append(Rect2(r.position / DOWNSAMPLE, r.size / DOWNSAMPLE))
	stats = measure(frame, exclude)


func _draw() -> void:
	draw_rect(Rect2(Vector2.ZERO, BOX), Color(0.05, 0.055, 0.06, 0.86))
	if stats.is_empty():
```

```gdscript
class_name PerfHud
extends Label
## Live cost readout (top right, under the view HUD): fps, CPU and GPU frame time, draw calls
## and primitives, averaged over INTERVAL. At 800+ fps, milliseconds are the honest unit.

const INTERVAL := 0.5

static func format(fps: float, cpu_ms: float, gpu_ms: float, draw_calls: int, primitives: int, probe_on: bool) -> String:
	var text := "%d fps   CPU %.2f ms   GPU %.2f ms\n%d draws   %s prims" % [roundi(fps), cpu_ms, gpu_ms, draw_calls, _short(primitives)]
	if probe_on:
		text += "\nprobe on: its readback adds a few ms every 0.25 s"
	return text


static func _short(n: int) -> String:
	if n >= 1_000_000:
		return "%.1fM" % (n / 1_000_000.0)
	if n >= 1000:
		return "%dk" % roundi(n / 1000.0)
	return str(n)


func _ready() -> void:
	add_to_group("overlay")
	mouse_filter = MOUSE_FILTER_IGNORE
	set_anchors_and_offsets_preset(PRESET_TOP_RIGHT)
	grow_horizontal = GROW_DIRECTION_BEGIN

	add_theme_color_override("font_color", Color(0.75, 1.0, 0.75, 0.9))
	add_theme_color_override("font_outline_color", Color(0, 0, 0, 0.8))
	add_theme_constant_override("outline_size", 4)
	visible = false
	visibility_changed.connect(_on_visibility_changed)

func _reset() -> void:

	_frames = 0
	_cpu = 0.0
	_gpu = 0.0


func _process(delta: float) -> void:
	if not visible:
		return

		int(Performance.get_monitor(Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME)),
```

```gdscript
class_name LightGizmos
extends MeshInstance3D
## Draws every visible omni light's range, every spot light's cone and the sun's direction on
## top of everything (no depth test), so light coverage reads through the trees. Rebuilt each
## frame because the lantern moves with the player. Vertices are in world space: keep this node
## at the playground's origin.

const SEGMENTS := 32
const SUN_ARROW := 3.0  # m

var pg: Node
var _lights: Array[Light3D] = []
var _mesh := ImmediateMesh.new()


## Line-segment pairs for a circle of `radius` around `center` in the plane of axes a and b.
static func circle(center: Vector3, a: Vector3, b: Vector3, radius: float, segments := SEGMENTS) -> PackedVector3Array:
	var out := PackedVector3Array()
	for i in segments:
		var t0 := TAU * i / segments
		var t1 := TAU * (i + 1) / segments
		out.append(center + (a * cos(t0) + b * sin(t0)) * radius)
		out.append(center + (a * cos(t1) + b * sin(t1)) * radius)
	return out


## A spot light's reach: a rim whose points are all `reach` from the apex, plus edges to it,
## so the outline shows the true range at the cone's edge.
static func cone(xf: Transform3D, reach: float, angle_deg: float, edges := 8) -> PackedVector3Array:
	var angle := deg_to_rad(angle_deg)
	var forward := -xf.basis.z.normalized()
	var right := xf.basis.x.normalized()
	var up := xf.basis.y.normalized()
	var rim_center := xf.origin + forward * reach * cos(angle)
	var rim_radius := reach * sin(angle)
	var out := circle(rim_center, right, up, rim_radius)
	for i in edges:
		var t := TAU * i / edges
		out.append(xf.origin)
		out.append(rim_center + (right * cos(t) + up * sin(t)) * rim_radius)
	return out


static func arrow(from: Vector3, direction: Vector3, length: float) -> PackedVector3Array:
	var d := direction.normalized()
	var tip := from + d * length
	var side := d.cross(Vector3.UP)
	if side.length_squared() < 0.001:
		side = Vector3.RIGHT
	side = side.normalized()
	return PackedVector3Array([from, tip, tip, tip - d * 0.6 + side * 0.3, tip, tip - d * 0.6 - side * 0.3])


func _ready() -> void:
	mesh = _mesh
	cast_shadow = GeometryInstance3D.SHADOW_CASTING_SETTING_OFF
	var material := StandardMaterial3D.new()
	material.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
	material.vertex_color_use_as_albedo = true
	material.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA  # drawn after opaque geometry
	material.no_depth_test = true
	material_override = material
	visible = false
	visibility_changed.connect(_on_visibility_changed)


func _on_visibility_changed() -> void:
	if visible:
		_lights.assign(pg.find_children("*", "Light3D", true, false))
	_rebuild()


func _process(_delta: float) -> void:
	if visible:
		_rebuild()


func _rebuild() -> void:
	_mesh.clear_surfaces()
	if not visible:
		return
	var points := PackedVector3Array()
	var colors := PackedColorArray()
	for light in _lights:
		if not is_instance_valid(light) or not light.is_visible_in_tree():
			continue
		var xf := light.global_transform
		var segment := PackedVector3Array()
		if light is OmniLight3D:
			var r: float = light.omni_range
			segment.append_array(circle(xf.origin, Vector3.RIGHT, Vector3.FORWARD, r))
			segment.append_array(circle(xf.origin, Vector3.RIGHT, Vector3.UP, r))
			segment.append_array(circle(xf.origin, Vector3.FORWARD, Vector3.UP, r))
		elif light is SpotLight3D:
			segment = cone(xf, light.spot_range, light.spot_angle)
		elif light is DirectionalLight3D:
			segment = arrow(pg.player.global_position + Vector3.UP * 2.5, -xf.basis.z, SUN_ARROW)
		points.append_array(segment)
		for i in segment.size():
			colors.append(light.light_color)
	if points.is_empty():
		return
	_mesh.surface_begin(Mesh.PRIMITIVE_LINES)
	for i in points.size():
		_mesh.surface_set_color(colors[i])
		_mesh.surface_add_vertex(points[i])
	_mesh.surface_end()
```
