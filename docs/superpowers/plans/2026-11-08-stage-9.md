# Stage 9 Implementation Plan: wind-driven grass, profiling, cleanup, reuse

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add painted, wind-driven grass that leans and carries travelling gust waves in a tunable
wind direction. Then profile the scene against a 60 fps mid-range budget, clear the Stage 8
leftovers, and document how to reuse the kit in a new level.

**Architecture:**
- **Wind.** A `Wind` node (`@tool`) owns the wind: strength, direction and a scrolling gust
  offset. It publishes them as global shader uniforms. One shader include (`wind.gdshaderinc`)
  turns them into a shared gust field that grass, trees and cloth all read.
- **Grass data.** A `GrassField` node (`@tool`) holds an RG8 mask (R = density, G = height), caches
  ground heights by raycasting against physics layer 2 ("ground"), and builds `MultiMesh` chunks.
- **Painting.** `GrassBrush` holds the painting logic, which keeps it testable. A thin
  `EditorPlugin` in `addons/grass_painter/` feeds it 3D-viewport input and wraps each stroke in one
  undo step.

**Tech Stack:** Godot 4.6 (mono build, pure GDScript), Forward+. One project-local editor plugin
(approved exception, see the spec).

**Spec:** `docs/superpowers/specs/2026-11-08-stage-9-design.md`. Read it before starting. This plan
makes these calls inside the spec's "left to the builder" space:
- Wind state moves from the playground into a reusable `Wind` node, so future levels and the
  editor preview get wind without the playground.
- Mound collision comes from a `collision` flag on `kit_asset.gd`, not from glb import settings.
- The starter mask is generated by a one-off script, `tools/make_starter_grass.gd`.

## Global Constraints

- **Engine:** Godot **4.6**, pure GDScript. No third-party addons, no paid or cloud services. The
  only plugin is `addons/grass_painter/`, and it paints grass masks and nothing else.
- **Style:** tabs, `##` doc comments, typed variables, the existing naming style. Read the
  neighbouring code before writing.
- **No git:** the project is **not** a git repo. Before Task 1, copy `scripts/`, `scenes/`,

  with a full-suite checkpoint.
- **Wind direction:** a compass angle in degrees, `0–360`. It names the direction the wind blows

  `vector = Vector2(sin(rad), -cos(rad))`. The default is `53.13`, which equals the old
  `WIND_DIR (0.8, -0.6)`.
- **Global shader uniforms** (`project.godot [shader_globals]`): `wind_strength` (float, 0.6),

- **Physics layers:** layer 1 = `"world"`, layer 2 = `"ground"` (name both in `project.godot`).
  Walkable ground is on **both** (`collision_layer = 3`). Grass and the brush ray **only** against
  layer 2.

- **Params:** `wind_direction` goes into `PARAM_ORDER` right after `"wind"`; `grass_visible` goes

- **Overlays:** anything drawn over the 3D view joins the group `"overlay"`.

## Review Focus

1. **A wind slider dragged fast, or the direction swung 180°.** The grass and trees turn smoothly,
   with no jump in the gust pattern, because the offset is integrated and never derived from
   `TIME × speed`. Test: `test_gust_offset_has_no_jump` (Task 1).
2. **Painting off the field's edge, or with a brush bigger than the field.** Only in-bounds texels
   change, with no error or out-of-range write. Test: `test_paint_clips_at_field_edge` (Task 3).
3. **A blade over a hole in the ground** (no hit on layer 2, such as off the Ground plane or over a
   boulder that isn't ground). It gets no blade; it doesn't sit at y = 0 or on top of the boulder.
   Tests: `test_boulders_are_not_ground` (Task 2) and `test_no_blades_where_ground_missing`
   (Task 3).
4. **Undo after a stroke that was painted and then rebuilt.** One Ctrl+Z restores the exact
   previous mask and blades. Test: `test_stroke_undo_restores_mask_and_blades` (Task 6).
5. **A hand-edited preset with `"wind_direction": "north"`, or an old preset without the key.**
   The bad value is skipped with a note; a missing key falls back to the default. Tests:
   `test_wrong_typed_preset_value_is_skipped` (Task 9) and `test_old_preset_keeps_default_direction`
   (Task 1).

### Task 3: GrassField — mask, painting, ground cache, chunks

**Files:**
- Create: `scripts/environment/grass_field.gd`, `assets/shaders/grass.gdshader` (colour only in
  this task; wind comes in Task 4), `tests/test_grass_field.gd`

**Interfaces:**
- Produces: `class_name GrassField extends Node3D` (`@tool`), with:
  - `const CHUNK_SIZE := 16.0`
  - `enum PaintMode { DENSITY, HEIGHT, ERASE }`
  - `signal rebuilt(blade_count: int)`
  - Exports (rebuild on change, as `Scatter` does with `mark_dirty`):
    - `extent := Vector2(74, 104)`
    - `texel_size := 0.5`
    - `mask: Image`
    - `blades_per_m2 := 24.0`
    - `min_height := 0.25`
    - `max_height := 0.9`
    - `random_seed := 1`
    - `ground_layer := 2`
    - `base_color`, `tip_color` (pick near `ground.tres` `(0.16, 0.17, 0.15)`; tip lighter and
      slightly warm)
    - `fade_start := 25.0`, `fade_end := 45.0`
  - `func mask_size() -> Vector2i`: `ceil(extent / texel_size)`
  - `func ensure_mask() -> void`: creates an `Image.FORMAT_RG8` of `mask_size()`, filled with
    `(0, 0.5)`, if `mask` is null. If the size is wrong, resizes it (bilinear) instead.
  - `func sample(world_xz: Vector2) -> Vector2`: bilinear `(density, height)`, `(0, 0)` outside
  - `func paint(world_pos: Vector3, radius: float, mode: PaintMode, target: float, strength: float, falloff := 0.5) -> Rect2i`
    - For each texel centre within `radius`: `w = strength * (1 - smoothstep(radius * (1 - falloff), radius, d))`.
    - DENSITY moves R toward `target`, HEIGHT moves G toward `target`, ERASE moves R toward 0, each
      by `lerp(v, target, w)`.
    - Returns the changed texel rect, clipped to the mask, or an empty `Rect2i()` if nothing
      changed.
  - `func set_mask_data(image: Image) -> void`: copies into `mask` and rebuilds everything (used
    by undo)
  - `func rebuild(texel_rect := Rect2i()) -> void`: an empty rect rebuilds every chunk; otherwise
    only chunks touching the rect grown by 1 texel
  - `func refresh_ground() -> void`: re-raycasts the height cache, then rebuilds
  - `func ground_height_at(world_xz: Vector2) -> float`: bilinear from the cache, `NAN` if any
    surrounding sample missed
  - `func blade_count() -> int`
  - `func chunk_instance(chunk: Vector2i) -> MultiMeshInstance3D`: null for an empty chunk
  - `static func blade_mesh() -> ArrayMesh`: a tapered blade of 3 segments (7 vertices), 1 unit
    tall, with `UV.y` = 0 at the base and 1 at the tip
- **Placement algorithm** (fixed, because tests depend on it being stable):
  - Each chunk gets an RNG seeded with `hash([random_seed, chunk.x, chunk.y])`, and
    `int(blades_per_m2 * CHUNK_SIZE²)` candidates.
  - Each candidate draws all of its randoms up front, in this order: x, z, keep, height jitter
    (±15%), yaw, lean (±10°), custom (tint, phase, fade).
  - A candidate is kept if `keep < sample().x` and `ground_height_at` isn't `NAN`.
  - Height = `lerp(min_height, max_height, sample().y) * jitter`.
  - `INSTANCE_CUSTOM` = `Color(tint, phase, fade_rand, 0)`.
  - Chunk nodes are internal children with no owner (not saved), named `"Chunk_%d_%d"`.
    `cast_shadow = OFF`, `visibility_range_end = fade_end + CHUNK_SIZE`.
- The ground cache is one height per texel centre, raycast from y = 40 down to y = −5 against
  `ground_layer`. It's computed lazily, on the first rebuild after `_ready`, waiting for the
  physics frame.

### Task 4: Grass shader — lean, gust waves, highlight, distance fade

**Files:**
- Modify: `assets/shaders/grass.gdshader`, `scripts/environment/grass_field.gd` (pass the fade
  uniforms)
- Test: `tests/test_grass_wind.gd`

**Interfaces:**
- Consumes: `wind.gdshaderinc` (`wind_gust`, `wind_direction`, `wind_strength`), and
  `INSTANCE_CUSTOM` from Task 3.
- Produces: grass shader uniforms `bend := 0.9` (tip offset in blade heights at strength 1, full
  gust), `flutter := 0.08`, `highlight := 0.18` (tip brightening at full gust), `fade_start`,
  `fade_end`, `base_color`, `tip_color`.
- Shader behaviour:
  - **Lean:** offset = `wind_direction * wind_strength * (0.35 + 0.65 * wind_gust(instance_xz)) * bend * UV.y²` in world space,
    applied to the vertex's world position. The base stays planted.
  - **Flutter:** per-blade `sin(TIME * 7 + phase * 6.283) * flutter * wind_strength * UV.y`,
    sideways to the wind.
  - **Highlight:** `ALBEDO *= 1 + highlight * gust * UV.y`.
  - **Fade:** `keep = 1 - smoothstep(fade_start, fade_end, camera distance)`. A blade with
    `fade_rand > keep` collapses to zero size. Blades near the threshold shrink in height first,
    so there is no popping line.
